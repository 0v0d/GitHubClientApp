# GitHub Client App

GitHubのAPIを使用したAndroidアプリケーションのサンプルプロジェクトです。
マルチモジュールの学習を目的として作成。

## 🛠 使用技術

### コア技術
- 🎯 **Kotlin** - Androidアプリケーション開発言語
- 📱 **Jetpack Compose** - モダンなUIツールキット
- 🏗 **マルチモジュール構成** - スケーラブルなプロジェクト構造

### 主要ライブラリ
- 🔄 **Ktor** - KotlinベースのHTTPクライアント
- 💉 **Koin** - 軽量な依存性注入フレームワーク
- 🖼 **Coil** - 画像ローディングライブラリ

## 🏗 プロジェクト構成

構成は以下となっています：

```
app/
├── app/           # アプリケーションのエントリーポイント、DI設定
├── domain/        # ビジネスロジックとモデル
├── data/          # データソース、リポジトリ、APIクライアント
└── feature/       # UI機能とプレゼンテーションロジック
```

### モジュール詳細

- **app**: アプリケーションの設定とDIの初期化
- **domain**: ビジネスモデルとユースケース
- **data**: KtorによるAPI通信を含むデータ層の実装
- **feature**: Jetpack Composeで構築されたUI要素

## ⭐️ 主な機能

- GitHubリポジトリの一覧表示
- リポジトリ詳細の表示
- Jetpack ComposeによるモダンなUI
- Koinを使用した依存性注入
- Kotlin Coroutinesによる非同期処理
- Coilによる画像の読み込み

## 📝 動作環境

- 最小 SDK: 24
- ターゲット SDK: 35
- Kotlin: 2.0.21
- java: 1.8
